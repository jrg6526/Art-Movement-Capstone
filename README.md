# Art Movement Capstone
This project is for my final class in Software Development. It covers art movements, such as their histories and lists of artworks in those movements. This project will be updated over time.

Since this project uses server-side scripts and a database, you must follow these instructions: 

## Instructions
1. Download [XAMPP](https://www.apachefriends.org/).
2. Install it with PHP and SQL.
3. Navigate to the directory you've installed XAMPP on.
4. Put the "Art Movements" folder in the htdocs directory.
5. Open xampp_control.exe and start Apache and MySQL.
6. Click "Admin" next to the MySQL module.
7. Once the phpMyAdmin page opens up, click "Import" and select the art_movements.sql file.
8. After the import, go back to the control panel and click "Admin" next to the Apache module.
9. Navigate to the "Art Movements" directory. This should open up the main page of the Art Movements project.
